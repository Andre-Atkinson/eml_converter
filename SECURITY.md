# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities **privately** rather than opening a
public issue. Use GitHub's private vulnerability reporting — the **Report a
vulnerability** button under this repository's
[Security tab](https://github.com/Andre-Atkinson/eml_converter/security). You
should get an acknowledgement within a few days.

(If that button is not visible, enable private vulnerability reporting under
Settings → Advanced Security.)

## What to look at

`eml2msg` is a local command-line tool: it reads `.eml` files, writes `.msg`
files, makes no network connections, and stores no credentials. The areas most
worth scrutiny are:

- parsing of untrusted `.eml` input — handled by [MimeKit](https://www.mimekit.net/);
- the Finder Quick Action shell script generated by
  `tools/install_quickaction.py`;
- the dependency supply chain — third-party packages are pinned in
  `src/Eml2Msg/packages.lock.json`, enforced by `make verify`, and audited for
  known vulnerabilities on every CI run.

## Supported versions

Only the latest release on the `main` branch is supported.
